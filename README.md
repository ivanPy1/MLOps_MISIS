# MLOps Course - Homeworks

Этот репозиторий содержит домашние задания по курсу MLOps, посвященные различным аспектам развертывания и мониторинга ML-моделей в production.

## 📋 Список домашних заданий

### 🏠 Homework 1: Model Validation and Metrics

**Цель:** Настройка пайплайна валидации ML-модели с использованием DVC и автоматических проверок качества.

**Основные задачи:**
- Интеграция Poetry для управления зависимостями
- Настройка pre-commit хуков (black, ruff, isort)
- Реализация скрипта валидации модели с проверкой accuracy
- Модификация DVC пайплайна с добавлением стадии валидации
- Сохранение метрик в JSON формате

**Технологии:** Python, DVC, Poetry, Pre-commit, scikit-learn

---

### 🚨 Homework 2: FastAPI Service Monitoring

**Цель:** Создание системы мониторинга для FastAPI сервиса с настраиваемыми алертами и цветным логированием.

**Основные задачи:**
- Мониторинг эндпоинтов `/health` и `/predict`
- Отслеживание метрик: Response Time, P95 Latency, Error Rate
- Реализация системы цветных алертов (зеленый/желтый/красный)
- Тестирование инференса ONNX модели
- Конфигурируемые пороговые значения через YAML

**Технологии:** FastAPI, ONNX, HTTP мониторинг, цветное логирование, YAML конфиги

---

### 🎬 Homework 3: RAG System for Animation Generation

**Цель:** Разработка RAG-системы для создания анимаций из текстовых описаний.

**Основные задачи:**
- Создание GIF анимаций по текстовым запросам
- Работа с базой данных поз (96 поз с описаниями)
- Интеграция с Ollama для обработки текста
- Использование Pose API для генерации поз
- Создание анимации танца "Макарена" по запросу

**Технологии:** RAG, Ollama, FastAPI, GIF generation, pose estimation

---

## 🛠 Установка и запуск

Каждое домашнее задание находится в отдельной директории с собственным README и инструкциями по установке.

Общие требования:
- Python 3.8+
- Poetry
- DVC (для Homework 1)
- Docker (опционально)
